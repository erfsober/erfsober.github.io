# Sleek Minimal Portfolio

A dark, minimal portfolio for a full-stack developer (Laravel, Blade, Livewire, SaaS, microservices, admin panels, HTML to Blade).

The site uses plain HTML, CSS and JavaScript, so it can be published directly with GitHub Pages.

## Replace your content

Edit `index.html` and replace:

- `Erfan Sabouri`
- `erfansabouri.dev`
- bio / introduction
- skills
- project names, descriptions and dates
- experience and education
- email
- GitHub and LinkedIn links

## Project screenshots

Each project has up to 3 screenshots in:

```text
assets/projects/<project-slug>/1.webp
assets/projects/<project-slug>/2.webp
assets/projects/<project-slug>/3.webp
```

Add your WebP images. If you use another format, update the `src` paths in `index.html`. To show fewer than 3, delete the extra `<button class="tile-shot">` lines.

Clicking a screenshot opens a full-screen gallery with previous/next controls.

## Resume

Add your PDF as:

```text
assets/resume.pdf
```

## Publish on GitHub Pages

Upload these files to a GitHub repository and enable:

**Settings → Pages → Deploy from a branch → main → / (root)**

For a personal site, you can name the repository:

```text
yourusername.github.io
```
